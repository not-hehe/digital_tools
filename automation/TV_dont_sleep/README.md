# TV Don't Sleep

Расширение Firefox для телевизоров, на которых крутятся дашборды.

## Задача

Дашборд на большом экране в офисе решает две проблемы сразу, и обе неприятные.
Экран засыпает по таймауту энергосбережения, и вместо графиков висит чернота.
А открытая на сутки вкладка показывает данные, загруженные утром, потому что
сама она не обновляется.

Расширение закрывает оба случая: листает вкладки текущего окна по таймеру,
перезагружает каждую перед показом и удерживает экран включённым через
Screen Wake Lock.

## Как пользоваться

Клик по иконке на панели включает и выключает карусель, состояние видно
на бейдже. Интервал показа и паузу после обновления страницы можно поменять
в настройках расширения.

Состояние переживает перезапуск браузера: если карусель работала, после старта
Firefox она продолжит работать.

Чтобы экран действительно не гас, расширению нужен доступ к данным на всех
сайтах, в Firefox MV3 он выдаётся вручную. Настройки энергосбережения самой
системы и телевизора тоже стоит проверить, расширение отвечает только за
браузер.

## Установка и исходники

Код и инструкция по установке лежат в [borderify/](borderify/README.md).

Собранный подписанный пакет в репозиторий не коммитится. Это артефакт сборки:
исходники рядом, а подпись сделана по конкретному содержимому и разойдётся
с кодом при первой же правке. Место готового пакета в GitHub Releases.
