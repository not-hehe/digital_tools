затронуты, как проверить, что не проверено.

## 2026-10-05 — массовое и одиночное падение, лог прогонов

**Что реализовано**
- Подтверждённое падение больше не идёт в канал само по себе. Массовое
  падение - не меньше `GROUP_MIN_DOWN` (3) доменов в окне
  `GROUP_WINDOW_MINUTES` (15) - сообщается сразу одним сообщением. Одиночное -
  только после `LONE_DOWN_HOURS` (16) часов непрерывного отказа. «Поднялся» -
  только про домены, о падении которых сообщали. У упавшего домена в
  состоянии появился признак `reported` и поля `url`, `contour`, `reason`.
- Текстовый лог прогонов `data/runs.log` (`DC_RUNLOG_FILE`): строка на каждый
  боевой прогон с именами не ответивших и строка на каждое событие. Предел
  `RUNLOG_MAX_LINES` (20000) с обрезкой с запасом. Ошибка записи прогон
  не роняет.
- Порог подтверждения падения `CONFIRM_FAILS` 2 -> 3 (с 21.09).

**Файлы**
`main.py`, `modules/config.py`, `modules/alerting/__init__.py`,
`modules/alerting/state.py` (`pick_alerts`), `modules/alerting/alert.py`,
`modules/alerting/runlog.py` (новый), `tests/test_logic.py`, `.env.example`,
`.gitignore`, README, `docs/architecture.md`, `docs/code.md`,
`docs/monitoring-practices.md`.

**Как проверить**
```bash
venv/bin/python tests/test_logic.py       # ожидается: Все 51 тестов пройдены.
venv/bin/python tests/test_e2e_local.py   # ожидается: Все 6 проверок пройдены.
T=$(mktemp -d)
for i in 1 2 3; do
  DC_STATE_FILE=$T/s.json DC_RUNLOG_FILE=$T/runs.log \
  DC_INPUT_FILE=data/input_urls.example.xlsx venv/bin/python main.py --no-notify
done
```
Третий прогон печатает сообщение «Упали: 6» с подписью про машину проверки
(в примере шесть адресов не резолвятся, они падают разом). В `$T/runs.log`
три строки `прогон` и шесть строк `упал`. Код возврата каждого прогона 0.

**Что не проверено**
- Поведение на боевом хосте: первый прогон после обновления пришлёт одно
  сообщение «Не отвечают дольше 16 часов» со всеми лежащими сейчас доменами,
  потому что в старом состоянии нет признака `reported`. Это разово.
- Версия Python на хосте; код держится совместимым с 3.9.

**Ограничения**
- Одиночный сайт может лежать до 16 часов без сообщения - принято
  сознательно, короче видно только в `data/runs.log`.
- Подпись отказа «TLS-рукопожатие не состоялось (устаревший протокол или
  шифр)» покрывает любую ошибку SSL, в том числе обрыв во время рукопожатия.
